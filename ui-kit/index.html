02

One honest verdict

Sagitta is a precision instrument with an editorial voice, not a marketing landing page. Roughly 80% of what these galleries sell would actively damage it. The valuable 20% is the motion engineering: one clock per reveal, springs that carry velocity, layout changes that animate automatically, exits faster than entrances, reduced motion by construction. Take that. Leave the shaders.

01

Counting number, one clock

Magic UI's Number Ticker + Animate UI's Sliding Number become sweepValue(). The gauge arc and the digits are the same value drawn twice — they can never disagree.

02

Ranked stagger, not random stagger

Motion's AnimatePresence + GSAP timeline become revealClock() with NexusReveal.Window. Hero → readings → footnote. Peers land together.

03

Calibrated rule, not a spinner

Magic UI's Scroll Progress becomes CalibratedRule: graduated ticks, lit only where the value has passed. A tick is real scale, never decoration.

04

Automatic layout motion

AutoAnimate's one-line add/remove/move becomes Modifier.animateItemPlacement() in every LazyColumn. No per-row choreography to maintain.

05

Everything collapses to zero

Animate UI and AutoAnimate both gate on reduced motion by default, matching LocalReducedMotion. Try the toggle in the top bar — the whole board obeys it.
